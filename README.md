# shoplite

A tiny storefront helper library (pagination, CSV product import, store time zones, cart totals).
Used as the demo repository for **PatchPilot**, a Rival CortexOne agent that turns GitHub issues into tested pull requests.

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Label an issue `autofix` to send it to PatchPilot (see `.github/workflows/patchpilot.yml`).
